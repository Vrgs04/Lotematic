# Imágenes autorizadas

Coloca aquí imágenes WebP propias o con licencia, una por figura, nombradas con el `slug` del catálogo (por ejemplo `el-gallo.webp`). Recomendación: 600×900 px, proporción 2:3 y menos de 150 KB. Si falta una imagen, Lotemática muestra automáticamente una tarjeta tipográfica; nunca descarga material externo.
